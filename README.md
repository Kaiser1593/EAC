# Entr'Aide et Culture (EAC)

Site statique de l'association : accueil (aide aux devoirs), infos et évènements, adhésion, dons.

- `js/config.js` : email de contact, lien de don, montants d'adhésion.
- `data/evenements.js` : ajouter un évènement par bloc, la page Infos se met à jour.
- Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages sur la branche principale.
